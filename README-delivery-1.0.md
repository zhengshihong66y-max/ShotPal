# 拉片宝交付版 1.0

最后更新：2026-06-19

本文件只描述 `交付版1.0` 分支。根目录 `README.md` 保持主线原始说明，不再承载交付版差异。

> 命名说明（2026-07-09）：原"交付版"系列从此改称 **Pro 版**。`交付版1.0`、`交付版1.1` 为历史分支名保持不变，后续版本使用 `Pro X.Y` 命名，当前工作分支为 `Pro1.2`。

## 分支定位

`交付版1.0` 是面向单人交付和轻量验收的分支，目标是保留拉片主流程，移除不适合当前交付阶段继续维护的独立管理界面和批量设置入口。

这个分支仍然围绕主页时间线完成视频播放、场景识别、截图、声音截取、字幕导出、音乐识别和资产导出。声音导出能力仍保留在主页，不再提供独立的音效管理工作区。

## 当前界面结构

左侧工作区只保留四个入口：

- **主页：** 播放视频、查看时间线、截图、批注、截取声音、导出字幕和查看音乐识别入口。
- **画面：** 浏览截图和场景代表帧，按视频查看分镜板，预览大图、编辑图片标签并回到原视频时间点。
- **音乐：** 只展示主页识别出来的音乐结果，并支持搜索、标签筛选、排序、封面、Apple Music 链接、原曲和伴奏下载。
- **设置：** 保留 `yt-dlp` 自检和快捷键参考。

## 已裁剪内容

- **设置页批量入口：** 已去除画面切分、音乐下载和字幕识别条目。
- **独立音效管理页：** 已去除左侧音效入口和 `Views/Audio` 下的相关界面文件。
- **账号登录删除：** 设置页不再提供账号登录、账号状态识别或浏览器登录态读取。
- **本地音乐管理：** 音乐工作区不再显示非主页识别来源的本地音乐文件。

## 保留能力

- **主页声音导出：** 主页里的 `提取声音`、In/Out 选区、导出声音选区、导出面板声音条目和音频文件落盘逻辑仍保留。
- **音频导出路径：** 声音片段仍导出到项目导出目录下的音效/音频文件夹，不受独立音效管理页删除影响。
- **网络导入：** 仅支持用户手动粘贴公开视频链接，不读取平台账号登录态，也不拉取收藏列表。
- **音乐识别结果：** 音乐界面只保留主页中能够识别出来的音乐，下载完成后继续关联对应识别结果。
- **下载音乐保留：** 由主页识别结果触发下载的原曲和伴奏会保留或恢复到素材库内的 `音乐` 文件夹，并继续被音乐界面识别、播放和生成波形。(Pro1.2 起调整：删除视频时,不再被任何其他视频引用的歌曲会连文件带记录一并清理;仍被引用的保留。)
- **非识别音乐打包：** 没有下载任务关联的外部音乐文件会移入素材库同级的 `素材库名-非识别音乐打包` 文件夹，不再留在素材库内部，也不进入音乐工作区列表。

## 交付前验证

本分支最近一次验证通过：

```bash
python3 Tools/regression_checks.py
xcodebuild -project LapianBao.xcodeproj -scheme LapianBao -configuration Debug -destination 'platform=macOS' build
```

后续只要改到 Swift 源码、工程配置、启动流程、导入下载、主页时间线、设置页或音乐工作区，都应重新跑以上两项检查。
